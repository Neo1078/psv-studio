Build Phases

Every project moves in the same three phases a building does.

Pick the phase you need, or run all three back to back — foundation, structure, finish-out.

PHASE 01

Foundation — Landing & Portfolio Sites

A single, cinematic one-page site: hero, case cards, contact block wired to your handles. Built the same way NEO YORK was — hand-coded, fast, no bloated site builder.

Site build plus a matching launch content pack: 3–5 branded social assets (carousel or flyer style) so the site doesn't launch into silence.

$1,000–$1,800 per bundle
PHASE 03

Finish-Out — Monthly Upkeep

Hosting checks, content swaps, and small updates so the site stays current without you touching code.

$150–$300 per month
